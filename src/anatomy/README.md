# Anatomy — Core v3

Anatomy.tsx reads the existing scoped workspace and selected astronaut. Accessible
system buttons update the authored SVG and supporting record panels. No external
anatomy asset, diagnostic image, disease coloring or 3D dependency is used.

This view uses canonical records and the shared assessment history. See
[CORE_V3.md](../../docs/CORE_V3.md). A future 3D renderer can replace the schematic
without inventing findings or changing record provenance.
